# 自己学習型オセロ

NumPy だけで実装した、自己対戦（self-play）で強くなるオセロAIです。

## 仕組み

- 盤面を「今どちらの手番か」の視点でベクトル化し、小さなニューラルネット
  （`othello/network.py`）に入力して「この局面から勝てる見込み」を出力させます。
- 学習前のネットは重みがランダムなので出力もでたらめですが、自己対戦を
  何百局・何千局と繰り返し、**対局が終わって分かった実際の勝敗**を教師信号
  として、対局中に通過した全局面の評価値をその結果に近づけていきます
  （`othello/agent.py` の `play_self_play_game`）。
- 着手選択は基本的に「一番評価値が高くなる手」を選びますが、学習中は
  一定確率でランダムな手も選び（epsilon-greedy）、序盤に手を広く試すように
  しています。学習が進むにつれ、このランダム率を下げていきます。
- 数百エピソードごとに、学習中のネットを「ランダムに打つだけの相手」と
  対戦させ、勝率の推移で強くなっているかを確認します。
- 1局打つごとに、その対局で通過した各局面を回転・鏡映で8通りに水増しして
  （結果はどの向きでも変わらないので無料のデータ拡張になります）経験リプレイ
  バッファに蓄積し、そこからランダムサンプルしたミニバッチで複数回学習します
  （`othello/train.py` の `ReplayBuffer`）。直近の1局だけで学習するより、
  過去局面を混ぜてミニバッチ化することで学習が安定します。

## セットアップ

```bash
pip install -r requirements.txt
```

## 学習

```bash
python -m othello.train --episodes 20000 --out othello_model.npz
```

- 数分〜数十分程度で、ランダム相手にはほぼ勝てるレベルになります。
  `--episodes` を増やすほど強くなりますが時間もかかります。
- 学習中は `eval-every` エピソードごとにランダム対戦の勝率を表示し、
  そのたびにモデルを `--out` のパスへ保存します（学習を中断しても
  それまでの結果は残ります）。
- `--replay-size`（リプレイバッファの容量）、`--batch-size`（ミニバッチ
  サイズ）、`--train-steps`（1局あたりの学習回数）で経験リプレイの挙動を
  調整できます。`--no-augment` で回転・鏡映によるデータ拡張を無効化できます。

## 対戦

```bash
python -m othello.play --model othello_model.npz --human-color black
```

- `d3` のように「列(a-h) + 行(1-8)」で着手を入力します。
- `--human-color white` にすると白番でプレイできます。

## デモ（CPU同士の対戦を観る）

学習済みAI同士を対局させて眺めることもできます。

### ターミナルで見る

```bash
python -m othello.demo --model othello_model.npz --delay 0.6 --games 3
```

`play.py` と同じ盤面表示で、AI同士が自動的に打ち合う様子を1手ずつ流します。
`--delay` で1手あたりの待ち時間、`--epsilon` でランダム性（対局ごとに展開を
変えるための確率、デフォルト0.1）を調整できます。

### ブラウザで見る

```bash
python -m othello.export_demo_games --model othello_model.npz --games 5 --out demo_games.json --html demo.html
```

AI同士の対局を指定局数プレイし、棋譜（各局面の盤面・着手・スコア）を
`demo_games.json` に書き出します。`--html` を付けると、その棋譜を埋め込んだ
`demo.html` も一緒に生成されます。生成された `demo.html` はサーバー不要で、
ブラウザでダブルクリックして開くだけで再生できます（再生/一時停止、1手ずつ
送り、シークバー、5局からの選択、棋譜一覧つき）。

## 発展させるなら

- `othello/agent.py` の `encode` に特徴量を足す（着手可能数の細分化、辺の
  安定石など）と学習が速くなります。
- モンテカルロ木探索（MCTS）を `choose_move` に組み込むと AlphaZero に
  近い、より本格的な自己対戦AIになります。
